# TarkovStats Discord Bot

Discord bot for AXIS Arena League matches in Escape from Tarkov: Arena, integrated with [TarkovStats](https://github.com/Namsr/tarkov-stats).

Used in `queue-<match number>` channels on the AXIS Discord server. The bot reminds players to upload the final scoreboard before choosing a winner, sends their screenshots to TarkovStats for recognition, and replies with the processing result in the same channel.

Screenshot recognition and player statistics are handled by TarkovStats.
